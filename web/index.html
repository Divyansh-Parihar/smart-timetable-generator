📋 Project Overview

The Smart Timetable Generator is a DAA (Design and Analysis of Algorithms) project that solves the NP-Hard timetable scheduling problem using two key algorithmic approaches:


① Graph Coloring (DSatur Algorithm)

The timetabling problem is modelled as a graph coloring problem:

  • Each class session = a graph node (vertex)
  • Two nodes share an edge if they conflict (same teacher or room)
  • Each color = a time slot
  • Goal: color the graph so no adjacent nodes share the same color
  • DSatur prioritizes the most-constrained vertex at each step → near-optimal coloring
  • Time Complexity: O(V² + E)

② Genetic Algorithm (Evolutionary Optimisation)

  • Chromosome: vector where chromosome[i] = time-slot for session i
  • Fitness: 1 / (1 + 10·hardConflicts + softConflicts)
  • Selection: Tournament selection (k=5)
  • Crossover: Single-point crossover
  • Mutation: Random gene reassignment (p=0.12)
  • Elitism: Top 4 survive each generation unchanged
  • Time Complexity: O(G × P × N²)

③ Pipeline

Graph Coloring runs first to produce a conflict-free seed, which initialises the GA population. The GA then refines further, optimising soft constraints like teacher workload distribution.
